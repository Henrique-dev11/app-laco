# Requisitos do MVP — Laço

## Objetivo

O MVP do Laço tem como objetivo permitir a conexão entre clientes que procuram cuidados para idosos e cuidadores que oferecem esses serviços.

O aplicativo mobile e a aplicação web utilizarão o mesmo backend através de uma API REST.

## Perfis

### Cliente

O cliente poderá:

- criar uma conta;
- cadastrar idosos;
- procurar cuidadores;
- consultar serviços;
- consultar disponibilidade;
- solicitar agendamentos;
- acompanhar contratos;
- realizar pagamento simulado;
- conversar com cuidadores;
- avaliar atendimentos concluídos.

### Cuidador

O cuidador poderá:

- criar e administrar seu perfil;
- cadastrar currículo;
- definir serviços oferecidos;
- definir disponibilidade;
- visualizar solicitações;
- acompanhar agendamentos;
- consultar contratos;
- conversar com clientes.

O cuidador poderá utilizar tanto o aplicativo quanto a aplicação web.

### Administrador

O administrador utilizará a aplicação web para:

- gerenciar usuários;
- analisar cuidadores;
- acompanhar agendamentos;
- acompanhar contratos;
- acompanhar pagamentos simulados;
- administrar serviços da plataforma.

### Super Administrador

O Super Administrador terá as permissões administrativas e também poderá:

- criar administradores;
- gerenciar administradores;
- bloquear administradores quando necessário.

## Funcionalidades principais

- Autenticação;
- Cadastro de clientes;
- Cadastro de cuidadores;
- Cadastro de idosos;
- Serviços;
- Disponibilidade;
- Agendamentos;
- Contratos;
- Pagamento simulado;
- Currículo;
- Conversas e mensagens;
- Avaliações;
- Painel administrativo.

## Fora do MVP

Funcionalidades que poderão ser implementadas futuramente:

- pagamentos reais;
- laudos;
- medicamentos;
- rotina detalhada do idoso;
- videochamadas;
- notificações avançadas.
