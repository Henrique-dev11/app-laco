# Aplicativo Laço

Aplicativo React Native com Expo SDK 58, incluindo execução web pelo Expo.

Siga a [instalação completa](../docs/instalacao.md) para preparar API, banco,
`mobile/.env` e Expo Go. Com o ambiente pronto, execute nesta pasta:

```sh
npm ci
npm run start:go
```

Pressione `w` no Metro para abrir o aplicativo no navegador.
